# Backend Resume Variants Design

## Goal

Create two ATS-friendly, one-page English resume variants for Singapore internships without claiming unfinished skills or projects.

## Shared Layout

- A4, single column, Arial, restrained blue headings.
- Header, targeted summary, technical skills, projects, competition, education.
- Placeholder contact details and real public GitHub links.
- No photos, icons, sidebars, skill ratings, or decorative charts.

## Java Backend Variant

Title: **BACKEND SOFTWARE ENGINEER INTERN**

Positioning: A backend-focused student with implemented Python/Flask/TCP systems and coursework exposure to Java, Spring Boot, MySQL, and React. The resume must not list the future Internship Application Tracker until its evidence gate is met.

Section emphasis:

1. Technical Skills, with Java/Spring Boot/MySQL/React explicitly labeled `Coursework Exposure`.
2. Federated Learning Platform first because it contains a Flask service, node management, TCP communication, model exchange, and live status updates.
3. RAG Study Assistant second, rewritten around modular services, API integrations, persistence, concurrency, and error recovery.
4. Competition and education compressed but retained.

## Python Backend / AI Systems Variant

Title: **BACKEND / AI SYSTEMS ENGINEER INTERN**

Positioning: A Python-oriented backend candidate with direct Flask, TCP socket, persistence, concurrent API processing, and AI-system integration experience.

Section emphasis:

1. Python, Flask, TCP sockets, API integration, persistence, concurrency, and Git.
2. RAG Study Assistant first, emphasizing ingestion services, concurrent API batches, persistent vector and sparse indexes, configuration, and recovery behavior.
3. Federated Learning Platform second, emphasizing distributed clients, model exchange, status polling, logs, and dashboard APIs.
4. Java/Spring Boot/MySQL/React remain coursework exposure.

## Future Upgrade

When the Internship Application Tracker meets its evidence gate, insert it as the first project in the Java variant and change Java, Spring Boot, MySQL, REST API, Spring Security, JWT, Docker, and CI/CD from coursework or learning items to project-backed skills. Add only measured JMeter results.
